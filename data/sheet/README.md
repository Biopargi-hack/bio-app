# Connected sheet mirror

This folder is generated by `python3 scripts/mirror_sheet.py`.

CSV files are the readable GitHub copy of the connected Tap to Prove Google Sheet. They use a UTF-8 BOM and semicolon separators so they open in Estonian Excel. The workbook snapshot is copied when the local sync workbook exists.

The sheet ID is read from `TAPTOPROVE_SHEET_ID` or the local sync folder. It is not stored in this repo.

Do not edit these files by hand. Refresh them after the sheet changes and commit the result.
